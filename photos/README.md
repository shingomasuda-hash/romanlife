# 写真の受け渡し用フォルダ

LPで使う実写をここへ置いてください。ファイル名は日本語のままで構いません。

## アップロード方法（GitHubのWeb画面）

1. GitHubでこのリポジトリを開く
2. ブランチを `claude/romanlife-event-lp-b1l9q6` に切り替える
3. `photos/` フォルダを開く
4. **Add file → Upload files** で写真をドラッグ＆ドロップ
5. **Commit changes**

> Google Drive はこの作業環境のネットワークポリシーで接続できないため、
> 直接取得できません。チャットへのファイル添付（ZIP可）でも構いません。
