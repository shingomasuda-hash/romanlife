# ロマンライフ 説明会・オープン・カンパニー2026 ／ 画像つなぎ版LP

デザインカンプ（`reference-images` の9枚）を**そのまま画像として連結**し、
ボタン位置に透明のリンク領域を重ねたLPです。
申込フォーム・会場アクセス・FAQ だけを HTML で実装しています。

> HTML/CSSでフルに組み直した版は `../static-lp/` にあります。
> 見た目の再現度は本バージョン（＝カンプそのもの）が最も高く、
> 文言修正や部分差し替えのしやすさは `static-lp` が上です。用途に応じてお選びください。

---

## 1. 使い方

ビルド不要です。

```bash
cd image-lp
python3 -m http.server 3000     # → http://localhost:3000
```

公開時は `image-lp/` の中身をそのままWebサーバーへ配置してください。
外部CDNへの通信は一切ありません（フォントも同梱）。

```
image-lp/
├─ index.html      画像パネル＋アクセス／FAQ／申込フォームのマークアップ
├─ styles.css      デザイントークン＋パネル・ホットスポット・フォームのスタイル
├─ script.js       日程データ／ホットスポット制御／フォーム処理
└─ assets/
   ├─ panels/      p01〜p09.webp（カンプを幅941pxへ正規化した画像）
   ├─ fonts/       明朝・欧文セリフ（使用文字のみサブセット化）
   ├─ favicon.svg  暫定ファビコン（★公式のものへ差し替えてください）
   └─ images/ogp.png
```

## 3. 透明リンク（ホットスポット）について

画像の上に `position:absolute` の `<a>` を **パネル幅に対する％** で配置しています。
画像を拡大・縮小しても比率で追従するため、どの画面幅でもボタンとズレません。

```html
<a class="hot" href="#entry-form" data-cta="hero"
   style="top:87.5%;height:7.2%;left:5.9%;width:88.1%"
   aria-label="説明会に申し込む（ページ下部の申込フォームへ移動します）"></a>
```

| 属性 | 役割 |
| --- | --- |
| `data-cta="hero"` / `data-cta="final"` | 申込フォームへスクロール＋計測イベント送出 |
| `data-pick="2026-08-11"` | 参加希望日をフォームへ反映 → フォームへスクロール → 参加希望時間へフォーカス |

- 最小の高さを 44px 確保しているため、スマートフォンでもタップしやすい大きさです。
- ホバー時はうっすら色が変わり、押せる場所であることが分かります。
- 締切を過ぎた日程のボタンは、画像の上に不透明の「受付終了」表示をかぶせて隠します。

**ボタン位置を調整したい場合**は `index.html` の `style="top:… height:… left:… width:…"` を
書き換えてください（数値はパネル画像に対する％）。

## 4. 画像を差し替える場合

`assets/panels/` の同名ファイルを置き換えてください。

- 幅は **941px** に揃えています。異なる幅の画像でも表示は崩れませんが、
  `index.html` の `<img width height>` を実寸に合わせて更新してください
  （読み込み中のガタつき防止のためです）。
- 差し替えで**ボタンの位置が変わった場合は、3章の％を測り直してください。**
- `alt` にはパネル内の文言をテキストで書き起こしています。画像を変えたら
  `alt` も合わせて更新してください。

## 5. ★ 開催日・時間・締切の変更

**`script.js` の `EVENT_DATES` だけ**を編集してください。
申込フォームの選択肢、確認画面、完了画面、締切判定がすべて同じデータを参照します。

締切は `2026-08-11T00:00:00+09:00` のように **日本時間の絶対時刻**で持っているため、
閲覧者の端末のタイムゾーン設定に関わらず同じ瞬間に締め切られます。

締切を過ぎると次の状態になります。

| | 動作 |
| --- | --- |
| 画像上の日程ボタン | 「受付終了」の表示をかぶせる。押すと理由を伝えてフォームへ誘導 |
| 申込フォームの選択肢 | `disabled` にして「（受付終了）」を表示 |
| 全日程が締切 | フォーム全体を「受付は終了しました」に切り替え |

> **画像内に焼き込まれた日付・時間・締切は書き換えられません。**
> 日程を変更する場合は `EVENT_DATES` に加えて、`assets/panels/p01.webp` `p08.webp` `p09.webp`
> （日付が写っているパネル）と各 `alt` も差し替えてください。

## 6. ★ 送信先（API）の設定

`script.js` の先頭に設定箇所をまとめています。**ダミーの外部URLは設定していません。**

```js
var ENTRY_API = null;          // 例: '/api/event-entry'
var PRIVACY_POLICY_URL = '';   // 例: 'https://www.romanlife.co.jp/privacy/'
```

- `ENTRY_API` が `null` のあいだは送信を行わず、確認画面から完了画面へ進むだけの動作になります。
- URLを設定すると、`buildPayload()` が組み立てたJSONを `POST` します。
- レスポンスは `{ "ok": true }` を成功とみなします。
  `{ "ok": true, "receiptNumber": "OC-260728-XXXXXX" }` を返すと完了画面に受付番号を表示します。
  失敗時は `{ "ok": false, "message": "…" }` を返してください。

送信されるデータ（`buildPayload()` 参照）:

```
submissionId / renderedAt / eventDateId / eventDateDisplay /
sessionId / sessionLabel / sessionTime /
lastName / firstName / lastKana / firstKana /
school / faculty / graduation / email / phone / referral / question /
privacyAgreed / privacyAgreedAt / companyName（ハニーポット）/
source{ utm_source, utm_medium, utm_campaign, utm_content, utm_term, referrer, pageUrl }
```

> **サーバー側でも必ず再検証してください。**
> 締切、必須項目、メール・電話の形式、`companyName` が空であること（ボット判定）は、
> ブラウザ側の検証だけに頼らず受け口側で必ず確認してください。

`PRIVACY_POLICY_URL` が未設定のあいだは、仮URLを置かずに「未設定です」と画面に明示されます。
公開前に必ず設定してください。

## 7. アクセシビリティ・SEOへの配慮

画像つなぎ版は、そのままだと**本文がすべて画像に埋もれてしまう**ため、次の対策を入れています。

- 全パネルに、記載内容を書き起こした `alt` を設定
- ファーストビューの直後に、開催日・時間・会場・対象・締切を **テキスト**で配置
  （視覚的には非表示、読み上げ・検索エンジンには読める `.panel-alt`）
- 透明リンクには `aria-label` で行き先を明示
- 会場アクセス・FAQ・申込フォームは通常のHTML

> それでも、文字の拡大・テキスト選択・翻訳・検索性の面では
> HTMLで組んだ `static-lp` のほうが有利です。
> 長期運用するページであれば `static-lp` をおすすめします。

## 9. ★ 公開前に確認・差し替えが必要なもの

| 項目 | 現状 | 対応 |
| --- | --- | --- |
| **パネル画像の人物写真** | ファーストビュー（`p01.webp`）はご支給画像。`p02`〜`p09` はカンプのAI生成画像 | `p02`〜`p09` を実際の社員・店舗写真で作り直してください |
| **送信先API** | 未設定（`ENTRY_API = null`） | 6章のとおり設定 |
| **プライバシーポリシーURL** | 未設定（画面に注意書きが出ます） | `PRIVACY_POLICY_URL` を設定 |
| **ファビコン** | 暫定の抽象マーク（企業ロゴ不使用） | `assets/favicon.svg` を差し替え |
| **OGP画像** | `assets/images/ogp.png`（自作） | 必要に応じて差し替え |

### 公式情報が確認できず、意図的に記載していないもの

- 参加費、具体的な定員・座席数
- 服装・持ち物（「申込み後の参加案内をご確認ください」としています）
- 当日の受付場所・入口（同上）
- 従業員数・店舗数（出典により数値が異なるため）

### ご支給いただいたFV画像に合わせて記載した内容

公開前に採用ご担当者さまへご確認ください。**

  「参加者限定の特別選考ルートをご案内します」に変更しました。
- **定員になり次第、受付を終了する場合がある** … FAQ に
  「申込みが締切前でも受付が終了することはありますか？」を追加しました。
