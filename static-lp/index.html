Section 02

はじめに・イベントの価値

Introduction / Event Value

お菓子を売る。
その先にある仕事を、知っていますか？

ロマンライフの仕事は、ただお菓子を販売することではありません。お客さまの大切な一日に寄り添い、商品、接客、空間、言葉を通じて、心が動く瞬間を生み出す仕事です。

今回の説明会（オープン・カンパニー）では、ロマンライフやお菓子・食品業界について知るだけでなく、販売職が大切にしている考え方をグループワークで体験できます。社員との座談会や社内見学を通じて、Webサイトだけでは分からない会社の空気を感じてください。

Section 05 — Company

京都から、
喜びをリレーする会社。

ロマンライフの始まりは、1951年、京都・河原町三条の小さな珈琲店でした。お客さまの好みに合わせて一杯のコーヒーを淹れる。その細やかなおもてなしの精神が、いまも私たちの原点です。

1982年に「京都北山 マールブランシュ」が生まれ、いまでは洋菓子の製造・販売にとどまらず、飲食店舗の運営、通信販売、移動販売まで。商品だけでなく、接客や空間も含めてブランドをつくり、京都で磨いた品質を、より多くの人へ届けています。

Section 06

接客から始まる、
さまざまなキャリア。

お客さまと直接向き合う販売・接客の経験は、ロマンライフのブランドや仕事を理解する大切な出発点です。

現場での経験を重ねた先には、店舗運営、スタッフ育成、マネジメント、商品企画、マーケティング、人事など、さまざまな仕事へ挑戦する可能性があります。

  1. 販売・接客
  2. 副店長・店長・
    リーダー
  3. 店舗運営・
    スタッフ育成
  4. エリアマネジメント／催事営業／商品企画／マーケティング／人事／経理／品質保証

キャリアの広がり方は一人ひとり異なります。適性、経験、成果、本人の希望、組織の状況などに応じて、担当する仕事は変わっていきます。希望する部署へ必ず異動できるものではありません。実際のキャリアの歩み方については、当日の座談会で社員に直接聞いてみてください。

ひとつのお菓子を届けるまでに、
たくさんの仕事がある。

お菓子の会社の仕事は、パティシエと販売職だけではありません。企画から、購買、製造、品質管理、物流、売場づくり、接客、広報まで。たくさんの仕事がつながって、ようやくお客さまの手に届きます。

  1. 01企画・
    マーケティング
  2. 02購買・製造
  3. 03品質管理
  4. 04物流
  5. 05売場づくり
  6. 06 接客・販売 今回体験するのはここ
  7. 07広報
  8. 08お客さまの体験

企画からお客さまの笑顔まで、それぞれの仕事がつながり、ロマンライフの幸せをつくっています。

販売職の役割

販売職は、
ブランドの最前線です。

「大切な方への贈り物」なのか、「自分へのご褒美」なのか。お客さまが何を求めて来られたのかを言葉と表情から読み取り、最適な商品と体験を届ける。それが販売職の仕事です。

ブランドの印象は、商品だけで決まりません。売場の空気、かけた一言、渡し方まで含めて、お客さまの記憶に残ります。今回のグループワークでは、その考え方を実際に体験していただきます。

Section 07 — Employee Talk

座談会 / employee-talk

仕事のことも、就活のことも。
直接聞いてみよう。

当日は、採用担当者との座談会の時間があります。数年前まで販売職として勤務していた先輩に、気になることをそのまま聞ける時間です。会社説明では出てこない話ほど、これからの進路を考えるヒントになります。うまく質問をまとめられなくても大丈夫です。

  • 入社を決めた理由は？
  • 実際に働いて感じたギャップは？
  • 接客で大切にしていることは？
  • 若手社員はどのような仕事を任される？
  • 社員同士の雰囲気は？
  • 就職活動で大切にしていたことは？
  • 仕事で成長したと感じる瞬間は？
  • 大変だった経験は？
  • 休日や働き方は？
  • 店舗で働く面白さは？
  • キャリアはどのように広がる？

申込フォームの「当日聞いてみたいこと」に書いていただいた内容も、当日の参考にさせていただきます。

  • ブランドを育てる仕事に興味がある
