# ロマンライフ 説明会・オープン・カンパニー2026 ／ 静的LP

`reference-images` のデザインカンプをもとに、HTML / CSS / JavaScript で実装した
2028年卒向け 説明会（オープン・カンパニー）LPです。
**画像を貼っただけのページではありません。** 見出し、本文、カード、ボタン、日程選択、
申込フォームはすべて実際のHTML要素として実装しています。

---

## 1. 使い方

ビルド不要です。`index.html` をブラウザで開けばそのまま表示されます。

```bash
# ローカルで確認する場合（webフォント等のパス解決のため簡易サーバー推奨）
cd static-lp
python3 -m http.server 3000     # → http://localhost:3000
```

公開時は `static-lp/` の中身をそのままWebサーバーへ配置してください。
外部CDNへの通信は一切ありません（フォントも同梱）。

```
static-lp/
├─ index.html          全セクションのマークアップ
├─ styles.css          デザインシステム＋各セクションのスタイル
├─ script.js           日程データ／フォーム処理／CTA連動
└─ assets/
   ├─ favicon.svg      暫定ファビコン（★公式のものへ差し替えてください）
   ├─ fonts/           明朝・欧文セリフ（使用文字のみにサブセット化）
   └─ images/          カンプから切り出した写真（WebP）
```

## 3. ★ 開催日・時間・締切の変更

**`script.js` の `EVENT_DATES` だけ**を編集してください。
日程カード、申込フォームの選択肢、最終CTAの日程表示、確認画面、完了画面が
すべて同じデータを参照しています。

締切は `2026-08-11T00:00:00+09:00` のように **日本時間の絶対時刻**で持っているため、
閲覧者の端末のタイムゾーン設定に関わらず、同じ瞬間に締め切られます。

締切を過ぎた日程は自動的に次の状態になります。

- 日程カード … 「受付終了」を表示し、選択ボタンを非表示
- 申込フォーム … 選択肢を `disabled` にして「（受付終了）」を表示
- 全日程が締切 … フォーム全体を「受付は終了しました」に切り替え

## 4. ★ 送信先（API）の設定

`script.js` の先頭に設定箇所をまとめています。**ダミーの外部URLは設定していません。**

```js
var ENTRY_API = null;          // 例: '/api/event-entry'
var PRIVACY_POLICY_URL = '';   // 例: 'https://www.romanlife.co.jp/privacy/'
```

- `ENTRY_API` が `null` のあいだは送信を行わず、確認画面から完了画面へ進むだけの動作になります。
- URLを設定すると、`buildPayload()` が組み立てたJSONを `POST` します。
- レスポンスは `{ "ok": true }` を成功とみなします。
  `{ "ok": true, "receiptNumber": "OC-260728-XXXXXX" }` を返すと、完了画面に受付番号を表示します。
  失敗時は `{ "ok": false, "message": "…" }` を返してください（メッセージが確認画面に表示されます）。

送信されるデータ（`buildPayload()` 参照）:

```
submissionId / renderedAt / eventDateId / eventDateDisplay /
sessionId / sessionLabel / sessionTime /
lastName / firstName / lastKana / firstKana /
school / faculty / graduation / email / phone / referral / question /
privacyAgreed / privacyAgreedAt / companyName（ハニーポット）/
source{ utm_source, utm_medium, utm_campaign, utm_content, utm_term, referrer, pageUrl }
```

> **サーバー側でも必ず再検証してください。**
> 締切、必須項目、メール・電話の形式、`companyName` が空であること（ボット判定）は、
> ブラウザ側の検証だけに頼らず、受け口側で必ず確認してください。

`PRIVACY_POLICY_URL` が未設定のあいだは、仮URLを置かずに
「未設定です」と画面に明示されます。公開前に必ず設定してください。

## 5. 実装している動作

| 機能 | 内容 |
| --- | --- |
| CTA | ページ内のすべてのCTAが最下部の申込フォーム（`#entry-form`）へ移動。外部媒体へは遷移しません |
| 日程カード連動 | ボタンを押すと参加希望日がフォームへ反映され、フォームへスクロール後、参加希望時間へフォーカス |
| 入力 → 確認 → 完了 | 送信は「この内容で申し込む」を押したときのみ。「修正する」で入力内容を保持したまま戻れます |
| 入力エラー | フォーム上部のサマリー（クリックで該当項目へジャンプ）＋各項目の直下に文章とアイコンで表示 |
| 二重送信防止 | 送信中はボタンを無効化し「送信しています…」を表示。多重リクエストを抑止 |
| 締切制御 | 上記3章のとおり |
| 固定CTA | スマートフォンのみ表示。フォーム到達中・入力中・確認/完了画面では自動的に非表示 |
| 計測 | `window.dataLayer` へ push（`cta_click` / `form_confirm_view` / `entry_complete` / `entry_error`）。GTM等を後から追加できます |

## 6. 表示確認の結果

375px / 390px / 768px / 1280px で確認済みです。

- 横スクロール：**発生なし**（全幅で `scrollWidth === clientWidth`）
- コンソールエラー：**なし**
- 外部通信：**なし**（フォント・画像はすべて同梱）
- axe-core（WCAG 2.0/2.1 A・AA）：**違反 0件**（1280 / 390 / 375px すべて）
- 入力文字・本文は 16px 未満にしていません
- ボタン・選択肢のタップ領域は 44px 以上（主要ボタンは 62px）

動作テスト（390px）:

| 項目 | 結果 |
| --- | --- |
| FVのCTA → フォームへ移動 | OK |
| 日程カード → 参加希望日へ反映 | OK |
| 参加希望時間へフォーカス誘導 | OK |
| 未入力時のエラー表示（12項目） | OK |
| 「その他」選択で追加入力欄が出る／戻すと隠れる | OK |
| 同意なしでは確認画面へ進めない | OK |

| 確認 → 修正 → 入力内容の保持 | OK |

## 7. ★ 公開前に確認・差し替えが必要なもの

| 項目 | 現状 | 対応 |
| --- | --- | --- |
| **写真** | デザインカンプから切り出したもの（AI生成画像）を使用 | 実際の社員・店舗写真へ差し替えてください（→ 8章） |
| **送信先API** | 未設定（`ENTRY_API = null`） | 4章のとおり設定 |
| **プライバシーポリシーURL** | 未設定（画面に注意書きが出ます） | `PRIVACY_POLICY_URL` を設定 |
| **ファビコン** | 暫定の抽象マーク（企業ロゴ不使用） | `assets/favicon.svg` を差し替え |
| **OGP画像** | `assets/images/ogp.png`（自作） | 必要に応じて差し替え |

### 公式情報が確認できず、意図的に記載していないもの

- 参加費、定員・座席数
- 服装・持ち物（「申込み後の参加案内をご確認ください」としています）
- 当日の受付場所・入口（同上）
- 選考優遇（有利とも不利とも読めない表現にしています）
- 従業員数・店舗数（出典により数値が異なるため）

掲載している数字は、公開情報で確認できた
**1951年（創業）／70年以上／1982年（マールブランシュ誕生）／3ブランド** のみです。
